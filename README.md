# Does Jumping Help Kids Grow Taller?

A one-page research overview on jumping, bone strength, and height in growing children, with a built-in mid-parental height calculator.

**Live page:** published with GitHub Pages from this repository.
**Full article:** [Does Jumping Make You Taller? — Doctor Taller](https://doctortaller.com/blogs/exercises/does-jumping-make-you-taller)

## What's on the page

- How impact from jumping helps growing bones become denser
- Key findings from controlled trials on jumping and bone strength in children
- What the evidence says about height, including an early 2025 study in children with short stature
- Why growth plate timing determines when jumping can make a difference
- A mid-parental height calculator (metric and imperial)
- Practical, low-risk tips for parents

## Height calculator

The calculator uses the mid-parental height method:

- Boys: (father's height + mother's height + 13 cm) ÷ 2
- Girls: (father's height + mother's height − 13 cm) ÷ 2

The result is shown with an approximate range of ±8.5 cm. It's a general estimate based on parents' heights only and doesn't account for bone age, growth trends, or puberty timing.
